# CSV Changer

契約データCSVをアップロードして、商品名でフィルタリング・必要なカラムのみを抽出するフロント完結型アプリです。

## 技術構成

- Next.js 15.1.3 (App Router)
- TypeScript
- Tailwind CSS
- Papa Parse
- encoding-japanese（日本語エンコーディング対応）

## セットアップ

### 1. 依存パッケージのインストール

```bash
npm install
```

### 2. 開発サーバーの起動

```bash
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開いてください。

## 機能

- CSVファイルのアップロード（.csvのみ）
- UTF-8・Shift_JIS・EUC-JPなど日本語エンコーディングの自動検出・変換
- 商品名の一覧表示と選択
- ステータス（契約中/解約済み等）での絞り込み
- **退会年月での絞り込み**（デフォルト：前月）
- 選択した商品名とステータスと退会年月でデータをフィルタリング
- **ダウンロード前のデータプレビュー表示**（最初の100件）
- **商品別カラムフォーマット設定**（LocalStorageに保存）
- 必要なカラムのみ抽出（デフォルト：顧客ID、電話番号、商品名、契約日、課金日、解約日、ステータス、料金）
- 整形済みCSVのダウンロード
- 空行の自動除外
- すべてブラウザ内で処理（サーバー処理なし）

## 使い方

1. 「CSVファイルを選択」ボタンをクリックしてCSVファイルを選択
2. 「CSVを読み込む」ボタンをクリック
3. 商品名のドロップダウンから抽出したい商品を選択
4. ステータスを選択（すべて/解約/契約中等）
5. 退会年月を選択（デフォルト：前月、または「すべて」を選択）
6. （オプション）フォーマット設定を展開して、抽出カラムを確認
7. 「データをプレビュー」ボタンをクリック
8. 抽出されたデータをテーブル形式で確認
9. 「このデータをダウンロード」ボタンをクリック
10. `[商品名]_[ステータス]_[退会年月]_[日付].csv` が自動ダウンロードされます

## 対応CSVフォーマット

契約データCSV形式：
- 商品名カラム必須
- 推奨カラム：顧客ID、電話番号、商品名、契約日、課金日、解約日、ステータス、料金

## 注意事項

- Shift_JISエンコーディングに自動対応（日本語の文字化けを防止）
- 空行は自動的に除外されます
- 2万件以上のデータでも快適に動作します
